Real pipeline

  1. Select the Remnant reference art.
  2. Select the driving motion video.
  3. Clip Forge uploads both files to WaveSpeed storage through the server.
  4. Wan2.2 Animate 2 generates the motion-transfer video.
  5. The result appears here and can be downloaded or added to the timeline.
Key safety: the API key stays on the server. Configure WAVESPEED_API_KEY; never put a real key in this HTML or GitHub.

Generate with Wan2.2

Wan2.2's official TI2V-5B model supports text-to-video and image-to-video at up to 720p/24fps. The repository documents a single-GPU run requiring about 24 GB VRAM for its 720p example.
